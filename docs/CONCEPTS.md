# Słownik domenowy

## Model + konfiguracja
Podstawowa jednostka benchmarku, np. `Amber Plus 3w1`. Kolor nie tworzy osobnej jednostki.

## Benchmark wewnętrzny
Porównanie wyłącznie produktów Lionelo w tej samej porównywalnej grupie. Powstaje dla co najmniej trzech modeli.

## Benchmark zewnętrzny
Porównanie modelu Lionelo z zatwierdzonymi modelami konkurencji w tym samym typie, konfiguracji i segmencie użytkowym.

## Segment użytkowy
Grupa produktów o podobnym zastosowaniu. Segment jest filtrem porównywalności; profile zmieniają wagi atrybutów wewnątrz segmentu.

## Profil użytkowy
Perspektywa oceny, np. miejski, terenowy lub podróżny. Ten sam zestaw atrybutów kategorii otrzymuje inne wagi.

## Atrybut kanoniczny
Ustandaryzowane pole kategorii z aliasami nazw i regułami jednostek, np. `waga_wozka_kg`.

## Evidence
Konkretny dowód wartości: fragment treści, źródło, data pobrania i metadane walidacji.

## Provenance
Łańcuch pochodzenia informacji od strony i surowego snapshotu do wybranej wartości benchmarkowej.

## Research run
Jedno uruchomienie pobierania i przetwarzania danych. Run zapisuje się zawsze, również przy wyniku częściowym lub braku zmian.

## Snapshot
Niezmienna wersja danych lub benchmarku tworzona tylko po istotnej zmianie. Ponowne pobranie tych samych danych nie tworzy snapshotu.

## Partial
Wynik częściowy po braku źródeł, błędzie lub przekroczeniu limitu kosztu. Produkt pozostaje widoczny z niższą kompletnością.

## EOL
Produkt wycofany. Jest archiwizowany i znika z aktywnych widoków, ale nie jest fizycznie kasowany z historii.
