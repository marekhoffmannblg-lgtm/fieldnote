# Priorytet źródeł

Dla parametrów technicznych: instrukcja/karta techniczna i producent > sklep branżowy > marketplace.
Dla ceny i dostępności: aktualne oferty sklepów i marketplace, deduplikowane po sprzedawcy.
Recenzje i social media są typami źródeł w modelu danych, ale nie są obsługiwane w MVP i nie rozstrzygają twardych parametrów.
