# Minimalna bramka publikacji

- Brak sekretów w historii Git i artefaktach frontendu.
- Publiczna rejestracja wyłączona.
- RLS i storage policies przetestowane dla odbiorcy, analityka i administratora.
- FastAPI odrzuca brak, wygasły i nieprawidłowy token.
- Endpointy administracyjne odrzucają role niższe niż admin.
- Firecrawl/OpenAI posiadają limity kosztu i czasu.
- Backup bazy i procedura rollbacku są opisane.
- HTTPS i bezpieczne nagłówki są aktywne.
